01

개요

Volibot은 Discord 서버 관리와 편의 기능을 제공하기 위해 운영에 필요한 최소한의 정보를 처리합니다. 본 방침은 처리하는 정보의 종류와 목적, 보관 및 삭제 기준을 설명합니다.

02

처리하는 정보

  • Discord 식별 정보서버 ID, 사용자 ID, 역할 ID, 채널 ID, 서비스가 생성하거나 관리하는 메시지 ID
  • 서버 설정관리·기록 채널, 자동 음성방, 입장·퇴장 안내, 역할, 티켓 및 기타 기능 설정값
  • 운영 및 관리 정보명령 실행과 권한 확인에 필요한 역할·권한 정보, 제재 사유, 관리자 메모 및 기능 수행 과정에서 생성되는 기록
  • 음성 상태 정보음성 채널 입장·퇴장 여부, 자동 음성방 소유자 및 기능 수행에 필요한 일시적인 상태
  • 이용자가 입력한 값방 이름, 모집 제목, 티켓·역할·관리 설정 등 명령 수행에 필요한 정보
  • LoL 계정 연결 정보기존에 저장된 Riot ID(게임 이름과 태그), LoL 서버, Riot 계정 식별자(PUUID)는 Discord 서버 ID 및 사용자 ID와 연결되어 있습니다. 기존 사용자 입력 연결은 Riot 계정 소유권 인증이 아닙니다. 현재 /롤 전적의 라이엇아이디 옵션으로 검색한 계정은 저장하거나 새로 연결하지 않습니다.
  • LoL 조회 정보Riot API에서 제공하는 현재 게임, 프로필, 공식 랭크, 최근 경기 및 챔피언 정보를 명령 수행에 사용합니다. 계정 연결 조회·해제 등 계정 명령 응답은 요청자에게만 표시됩니다. 전적 등 LoL 조회 결과는 명령을 실행한 채널에 공개 표시되며, 60초 후 자동 삭제됩니다. 페이지 이동·경기 선택은 요청한 사용자만 조작할 수 있습니다. API 호출을 줄이기 위해 조회 정보는 운영 프로세스 메모리에 일시적으로 캐시합니다.

Volibot은 음성 통화의 실제 오디오를 녹음하거나 저장하기 위한 기능을 제공하지 않습니다. 일반적인 기능 제공을 위해 Discord 메시지 내용을 지속적으로 수집·보관하는 것을 목적으로 하지 않습니다.

03

이용 목적

  • 경고·타임아웃 등 서버 관리 명령의 실행과 기록 조회
  • 자동 음성방 생성·관리 및 방 소유자 관리
  • 서버 설정 저장, 복원 및 관리 기능 제공
  • 입장·퇴장 안내와 관리자 활동 기록
  • 티켓, 역할 자동화, 모집 및 기타 편의 기능 제공
  • 등록 Riot 계정의 게임·전적·프로필 조회와 최근 경기 표본 통계 제공
  • 권한 확인, 오류 진단, 보안 유지 및 비정상적인 사용 방지
04

보관 및 삭제

서버 설정, 자동 생성 채널 관련 메타데이터, 관리 기록, 티켓·역할 설정 등 지속적인 기능 제공에 필요한 정보는 해당 기능을 제공하는 동안 보관될 수 있습니다. 기능 수행 과정의 일시적인 정보는 더 이상 필요하지 않으면 폐기합니다.

서버 관리자가 관련 설정을 초기화하거나 Volibot을 서버에서 제거하면 일부 데이터가 삭제 또는 갱신될 수 있습니다. 이용 중단 후 남아 있는 데이터의 확인·삭제가 필요한 경우 아래 문의 방법을 통해 요청할 수 있습니다.

Riot 계정 연결 정보는 기능 사용을 위해 데이터베이스에 저장됩니다. /롤 계정 해제를 실행하면 현재 Discord 서버에 저장된 본인의 계정 연결이 삭제됩니다. 다른 Discord 서버의 연결과 Riot 계정 자체는 삭제되지 않습니다.

05

외부 서비스 및 운영 인프라

Volibot은 기능 제공을 위해 Discord API와 Riot Games API를 사용하며, 서버·데이터베이스 등 운영 인프라 제공자가 서비스 운영에 필요한 범위에서 정보 처리에 관여할 수 있습니다. 각 외부 서비스에는 해당 서비스의 정책이 적용될 수 있습니다.

Volibot은 이용자의 개인정보를 판매하지 않습니다. 법적 의무가 있는 경우 관계 법령에 따라 정보가 제공될 수 있습니다.

06

보안

운영자는 접근 권한 제한, 비밀정보 분리, 데이터베이스 접근 통제 등 합리적인 기술적·관리적 조치를 통해 처리 정보를 보호하도록 노력합니다. 다만 인터넷을 통한 정보 처리의 절대적인 보안을 보장할 수는 없습니다.

07

이용자의 선택과 요청

서버 관리자는 Volibot의 기능을 비활성화하거나 앱을 서버에서 제거할 수 있습니다. 본인 또는 관리 중인 서버와 관련된 저장 데이터의 확인·삭제가 필요한 경우 운영자에게 요청할 수 있으며, 대상 식별을 위해 Discord 사용자 ID 또는 서버 ID 확인을 요청할 수 있습니다.

08

아동 및 청소년

Volibot은 Discord에서 허용되는 이용자를 대상으로 하며 별도로 아동의 개인정보를 수집하기 위한 서비스를 제공하지 않습니다. 이용자는 Discord의 연령 요건과 관련 정책을 준수해야 합니다.

09

정책 변경

서비스 기능, 운영 방식 또는 관련 규정이 변경되는 경우 본 방침을 수정할 수 있으며, 변경 시 본 페이지의 최종 수정일을 갱신합니다.

10

문의 및 삭제 요청

개인정보 관련 문의 또는 삭제 요청은 Volibot 공식 Discord 서버에서 운영자에게 요청할 수 있습니다. 개인정보가 포함된 내용은 공개 채널에 작성하지 말고, 운영자가 안내하는 별도의 확인 방법을 이용해 주세요.
